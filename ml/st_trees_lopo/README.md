# LOPO MEMS Studio tree reports

Place the four exported decision-tree text reports here as:

- `lopo_01.txt`
- `lopo_02.txt`
- `lopo_03.txt`
- `lopo_04.txt`

See `docs/LOPO_MEMS_STUDIO.md` for the fold mapping and final evaluation
command. Do not place UCF or generated C headers here in place of the text
reports; the Python evaluator parses the complete MEMS Studio tree report.
